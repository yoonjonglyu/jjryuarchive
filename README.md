# 전주류씨 아카이브 (Jeonju Ryu Clan Digital Archive)

> **전주류씨(全州柳氏)** 가문의 역사와 인물, 족보, 문화유산을 디지털로 기록하고 영구 보존하기 위한 **오픈 디지털 아카이브 프로젝트**입니다.

---

## 🚀 빠른 실행 방법 (Getting Started)

Windows 환경 및 일반 환경에서 모두 간편하게 실행할 수 있습니다.

### 방법 1. Windows 원클릭 실행 (추천)
저장소 루트에 있는 `dev.bat`을 더블 클릭하거나 콘솔에서 실행합니다.
```cmd
.\dev.bat
```

### 방법 2. npm 스크립트 실행
PowerShell 보안 정책(`PSSecurityException`)을 방지하기 위해 `npm.cmd`를 사용하거나, 루트 디렉토리에서 바로 실행합니다:

```bash
# 1) 루트 디렉토리에서 실행 시
npm.cmd run dev

# 2) 하위 프로젝트 디렉토리에서 실행 시
cd jjryuarchive
npm.cmd run dev
```

브라우저에서 **[http://localhost:3000](http://localhost:3000)** 으로 접속하여 아카이브를 열람하실 수 있습니다.

## 📖 소개

전주류씨 아카이브는 전통 문중 기록을 현대적인 웹 기술로 재정비하여  
누구나 쉽게 가문의 역사와 자료를 열람할 수 있도록 하는 **디지털 문헌 프로젝트**입니다.

- 가문의 시조와 분파 계통 (시조 완산부원군 류습 ~ 회헌공 류극서 ~ 수곡파 입향조 류성 ~ 파조 기봉 류복기)
- 주요 인물 약력 및 업적 (예안의병장 기봉 류복기, 대사헌 삼산 류정원, 예학의 대가 동암 류장원, 영남 사림의 종장 정재 류치명, 3대 독립운동가 서산 류필영·백하 류원식·류동시 등)
- 전주류씨 대동보 공인 데이터 기반 수곡파 주요인물 계보도(21대 71위) 및 세대별 탐색
- 안동댐 수몰사 기록 및 고문서, 문집(세계기록유산 유교책판), 사진 자료실
- 오픈소스 기반 영구 디지털 보존 (GitHub Global Vault)

## 🕊️ 작업 동기 (Project Motivation)

전주류씨 수곡파(水谷派)는 안동댐 건설로 인해 **집성촌이 수몰되며**  
오랜 세월 동안 이어오던 **문중의 중심지와 기록, 문화의 맥락이 단절**되었습니다.  

그 결과, 많은 후손들이 **자신의 뿌리와 역사에 접근하기 어려운 현실**에 놓이게 되었습니다.  
이 프로젝트는 그러한 상황 속에서 한 가지 걱정에서 비롯되었습니다.

> “만약 외세나 국가적 혼란으로 나라가 멸망한다면,  
>  제대로 된 문중의 역사가 사라지는 것은 아닐까?”

그 우려는 단순한 염려가 아니라,  
**가문과 역사를 지키기 위한 최소한의 기록 의무**로 이어졌습니다.  

따라서 본 프로젝트는 단순한 웹사이트가 아니라,  
**전주류씨의 기억을 디지털 언어로 다시 세우는 기록의 집**입니다.  
즉, 깃허브 아카이브 등 **글로벌 저장소**를 통해서 한국이 멸망해도 가문의 역사가 잊혀지지 않고 후손들에게 정확히 전달되도록 하기 위함입니다.

## 💡 주요 구현 기능

1. **수곡파 주요인물 계보도 시각화 (`/genealogy`)**  
   - 전주류씨 대동보(全州柳氏大同譜) 공인 데이터 기반 71위(位) 주요 선조 계보 수록
   - 1세 완산부원군 류습부터 21세 독립운동가 류동시까지 총 21세대 전수 체계화
   - 시대별 6대 역사 흐름 뷰(시대 그룹 플로우) 및 전체 카드 그리드 뷰 모드 지원
   - 종파·삼산공계·동암공계·칠잠공계 분파 필터링 및 이름/호/한자/관직 실시간 검색
   - 선조 선택 시 부모·자녀 관계, 대동보 권수/페이지 번호(Jokbo ID 링크) 및 상세 인적 정보 모달 제공

2. **인물 중심의 기록 체계화 (`/people`)**  
   - 시조 류습, 파조 기봉 류복기, 대사헌 삼산 류정원, 동암 류장원, 정재 류치명, 독립지사 서산 류필영·백하 류원식 등 주요 선조 프로필 등록  
   - 분야별(시조/중흥조, 의병/독립운동, 유학자, 관료) 필터링  
   - 생애, 업적, 저서, 관련 유적 데이터베이스화

3. **디지털 사료관 및 수몰사 기록 (`/archive`)**  
   - 유네스코 세계기록유산 유교책판 등재본 『삼산집』·『상변통고』, 기봉정사 상량문, 1974년 안동댐 수몰 전 수곡리(무실마을) 전경 및 이축 실측도 등 1차 사료 수록  
   - 사료 해제, 소장처(한국국학진흥원 등), 역사적 보존 가치 명시

4. **모바일 최적화 및 프리미엄 헤리티지 디자인**  
   - 전통 한지와 묵향(墨香)의 색채를 현대적인 디자인 시스템(Asharyu Theme)과 결합  
   - Next.js 16 (App Router) 기반 고속 정적 렌더링 및 모바일 반응형 완비
